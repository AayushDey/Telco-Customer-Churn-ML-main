## 🎯 What Is This?

ChurnSight is a full-stack ML system that predicts whether a telecom customer is likely to churn. It combines:

- A trained **XGBoost classifier** (ROC-AUC: **0.839**, Recall: **82.4%**)
- A **FastAPI** backend with single + batch prediction endpoints
- A **premium glass-morphism dashboard** with real-time results
- **SHAP explainability** — every prediction shows *why* the model decided what it did
- **SQLite prediction log** — full history with stats across all predictions

## 🚀 Quick Start

### 1. Clone & install

```bash
git clone https://github.com/AayushDey/Telco-Customer-Churn-ML-main.git
cd Telco-Customer-Churn-ML-main

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Validate your setup

```bash
python scripts/validate_setup.py
```

### 3. Get the dataset

Download from Kaggle: [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)  
Place the CSV at: `data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`

### 4. Run the training pipeline

```bash
python scripts/run_pipeline.py \
    --input data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv \
    --target Churn
```

This will:
- Validate data quality
- Engineer features (binary + one-hot encoding)
- Train XGBoost with class-imbalance handling
- Log metrics + save model to MLflow
- Save `feature_columns.txt` for serving consistency

### 5. Launch the dashboard

```bash
uvicorn src.app.main:app --reload
```

Open **http://localhost:8000** — you'll see the ChurnSight dashboard.

### Single prediction example

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "gender": "Female", "Partner": "Yes", "Dependents": "No",
    "PhoneService": "Yes", "MultipleLines": "No",
    "InternetService": "Fiber optic", "OnlineSecurity": "No",
    "OnlineBackup": "No", "DeviceProtection": "No",
    "TechSupport": "No", "StreamingTV": "Yes", "StreamingMovies": "Yes",

    "PaymentMethod": "Electronic check",
    "tenure": 4, "MonthlyCharges": 85.0, "TotalCharges": 340.0
  }'
```

**Response:**
```json

  "confidence": "High Confidence",
  "shap_values": [
    {"feature": "Contract: Month-to-month", "impact": 0.4231},

    ...
  ]
}
```


## 🧠 Model Details

| Property | Value |
|---|---|
| Algorithm | XGBoost (gradient boosted trees) |
| ROC-AUC | **0.839** |
| Recall (churners) | **82.4%** |
| F1 Score | 60.9% |
| Classification threshold | 0.35 (tuned for high recall) |
| Features | 30 engineered (binary + one-hot encoded) |
| Training samples | 5,634 |
| Class imbalance handling | `scale_pos_weight` |
| Explainability | SHAP TreeExplainer |

### Feature engineering pipeline

1. **Binary encoding** — `Yes/No` → `1/0`, `Male/Female` → `1/0`
2. **One-hot encoding** with `drop_first=True` (prevents multicollinearity)
3. **Feature alignment** — exact column order from training enforced at serving time

> **Train/serve consistency is guaranteed**: `feature_columns.txt` is saved at training time and loaded by `inference.py` to ensure the model always receives features in the correct order.

## 🔍 SHAP Explainability

Every `/predict` call returns top-8 SHAP feature importance values:

- **Positive impact** (red) = pushes prediction toward churn
- **Negative impact** (green) = pushes prediction away from churn

The dashboard renders these as an interactive horizontal bar chart under "🔍 Why this prediction?".
